**Full Stack**
`Node.js` `Express` `PostgreSQL` `JWT` `React`

Sistema para gerenciamento de resenhas de livros, desenvolvido com API REST, autenticação de usuários e banco de dados relacional.

O projeto foi desenvolvido com foco em colocar em prática conceitos de desenvolvimento full stack, integração entre front-end e back-end e persistência de dados.

### 💰 API REST GymPass

**Back-end**
`Node.js` `TypeScript` `Fastify` `Prisma` `PostgreSQL` `Docker` `Vitest`
